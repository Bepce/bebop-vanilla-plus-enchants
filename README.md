# Bebop Vanilla Plus Enchants

A small Fabric mod that adds a couple of enchantments I wanted for my own vanilla+ world. Nothing crazy, just quality-of-life stuff that hopefully still feels like it belongs in the game.

Anyone's welcome to use it, and if you've got ideas for more vanilla+ enchants (ones that don't break the game), throw them my way.

## Enchantments

### Strip Mining (pickaxes)
Sneak + mine an ore and the whole connected vein comes with it (up to 64 blocks). Fortune and Silk Touch still work like normal.

### Felling (axes, levels I-II)
Sneak + chop a log and the whole tree comes down.
- **Felling I**: normal 1x1 trees
- **Felling II**: big 2x2 trees too (dark oak, giant spruce, jungle)

It only works on actual trees (it checks for natural leaves), so your log cabin is safe.

### Both of them
- Every extra block costs durability like normal, and Unbreaking works like normal too
- They stop before your tool breaks, so your diamond pick won't die mid-vein
- You can't get them from the enchanting table or from librarians. You have to go find them.

## Where to find them

| Where | What |
|---|---|
| Mineshaft chests | Strip Mining or Felling |
| Dungeon chests | Strip Mining or Felling |
| Ancient City chests | Strip Mining or Felling |
| Trial Chamber vault (normal key) | Felling |
| Ominous vault (ominous key) | Strip Mining |

## Requirements

- Minecraft 26.3
- Fabric Loader
- Fabric API

This is barely tested and probably has bugs. Use at your own risk xd. Maybe back up your world before throwing it in.
